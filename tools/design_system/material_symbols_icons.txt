# Icons included in the shipped MaterialSymbols subset font.
# One icon name per line (names from MaterialSymbolsOutlined.codepoints).
# Comment lines and blanks are ignored; the list is deduped and sorted by the script.
# After editing, rerun:  .venv/bin/python tools/design_system/subset_material_symbols.py
# then regenerate font assets (make ds-setup).
#
# The V2 design (DESIGN_IMPLEMENTATION.md §3.7) is drawn with Flaticon glyphs; we ship
# the nearest Material Symbols equivalent (option (a)). Mapping:
#   fi-sr-home           -> home                 fi-ss-doctor       -> medical_services
#   fi-sr-map-marker     -> location_on          fi-ss-call-outgoing-> call
#   fi-sr-mode-landscape -> filter_center_focus  fi-ss-cross-circle -> cancel
#     (V2's Mergulho glyph is an AR-focus frame, NOT the mountains `landscape`
#      reads as — see the Tela 7 tile and the bottom-bar tab.)
#   alert-triangle       -> warning              fi-ss-plus-small   -> add
#   arrow-left           -> arrow_back           add_circle         -> add_circle
#   chart-column         -> bar_chart            close / x          -> close
#   compass              -> explore              chevron_forward    -> chevron_right
#   mail                 -> mail                 map-pin            -> location_on
#   user                 -> person               checkbox (Material kit) -> check_box*
# The Avistamentos tab's custom shark fin has NO equivalent — see the TODO at the end.
